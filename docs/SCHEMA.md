# Lynks Database Schema

> **Last updated:** August 22, 2026
> **Status:** All tables verified against live Supabase database

---

## Overview

All tables use UUID primary keys in the `public` schema. Auth is handled by Supabase's internal `auth.users` — a trigger copies id, email, and created_at into `public.users` on signup.

```
users ──< roadmaps ──< steps ──< tasks ──< evidence
users ──< resumes
users ──< conversations ──< messages
```

---

## users

| Field | Type | Constraints | Notes |
|-------|------|-------------|-------|
| id | uuid | PK, FK → auth.users.id | Set by trigger on signup |
| email | text | UNIQUE, NOT NULL | From Supabase Auth |
| username | text | UNIQUE, nullable | Set by user |
| name | text | nullable | Set by user |
| age | int8 | nullable | Set by user |
| country | text | nullable | Set by user |
| education_level | text | nullable | Set by user |
| career_path | text | nullable | Set by user |
| interests | text[] | nullable | Array of strings |
| created_at | timestamptz | NOT NULL, DEFAULT now() | Set by trigger |

**RLS:** SELECT/UPDATE where auth.uid() = id. INSERT via service role (trigger).
